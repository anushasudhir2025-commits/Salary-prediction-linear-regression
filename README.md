# Salary-prediction-linear-regression
## 📌 Project Overview
This repository contains a professional implementation of a Simple Linear Regression model to analyze the relationship between years of experience and annual income. 

## 📊 Key Findings
- **Correlation:** High positive correlation observed between professional tenure and salary.
- **Model Accuracy:** The model achieved an R² score of 0.9553.
- **Error Analysis:** Residual plots indicate that the linear assumptions hold true for this dataset.

## 🛠 Tech Stack
- **Language:** Python 3.x
- **Libraries:** Pandas (Data Handling), Scikit-Learn (Modeling), Seaborn/Matplotlib (Visualization), Joblib (Model Export).

## 📂 Repository Contents
- `LinearRegression.ipynb`: Documented analysis and model training.
- `salaries.csv`: Raw data source.
- `salary_model.pkl`: Pre-trained model for immediate deployment.
